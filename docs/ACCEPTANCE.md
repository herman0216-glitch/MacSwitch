## 自动化回归覆盖

- 统一队列：同一功能串行操作、读写失败后回读真实值、重试原目标、关闭时拒绝新命令及释放服务；过期后调整时长不会意外开启防休眠。
- 配置：默认五项可见、无快捷键、30 分钟；重启持久化；损坏配置回退并提示；顺序规范化与双向拖放后的持久化。
- Finder：刷新失败时恢复原值，包括原键不存在的情况；正常往返和重复设置。
- IOKit：倒计时、到期、手动关闭、无限时长、退出；查询失败不丢失持有的断言 ID，释放失败可重试。
- CoreAudio：默认设备切换、设备断开、不支持和只读属性、读取及写入失败、异步生效、写入后状态不匹配；不把旧设备静音意图写入新设备。
- 热键：重复绑定、系统注册冲突、保留旧绑定、清除、默认不注册；录制期间不触发本应用既有绑定。
- 外观：启动 System Events 后再检查权限；允许、拒绝和授权撤销；授权失败不写入；脚本部分生效后仍能读取真实状态；只读不会触发授权。

上述失败与撤销路径主要使用注入后端验证；没有为了制造故障而破坏真实 Finder、音频驱动或系统权限数据库。

## 验收边界与后续复验

- 内置设备的结果仅适用于本机。更换麦克风或扬声器后，应确认设备支持主静音属性，并实际检查声音输入/输出。
- 本轮未执行物理 USB / 蓝牙拔插、注销再登录、完整 30 / 60 分钟等待；分别已有真实 HAL 设备消失、SMAppService 注册状态、内核加速超时与自动化计时证据。
- 撤销授权后的错误路径由自动测试覆盖；实机覆盖权限关闭失败、用户允许后成功，没有再次撤销用户已授予的权限。
- Finder 偏好属于兼容实现。macOS 升级后应重复隐藏与恢复实测；恢复命令见 `README.md`。
- 本地 ad-hoc 签名重新构建可能触发系统重新确认自动化权限；本轮授权由用户操作。
