# MacSwitch v1.1.1 — 交互与兼容改进

发布日期：2026-10-01。版本：1.1.1（构建 3）。本次补丁发布汇总 v1.1.0 之后的桌面隐藏、外观切换、清洁模式与界面改进。

## 更新内容

- **桌面图标持续隐藏**：使用普通桌面与台前调度的双显隐偏好，并为桌面项目设置隐藏标记，避免点击墙纸、台前调度收起窗口时图标临时出现；自动隐藏新放入桌面的项目。关闭时只恢复 MacSwitch 隐藏的项目，原本隐藏的项目保持原状，支持通过书签恢复改名或移动的项目。不移动文件，不重启 Finder 或 Dock。
- **深色模式原生切换**：使用系统原生外观接口与过渡，移除 System Events 和自动化权限请求。点击后立即显示目标状态，以系统回读确认结果；连续点击串行处理，失败恢复实际状态，并处理回调超时、取消与退出竞态。
- **清洁模式输入保护**：使用独立的输入白名单和双层事件拦截，仅放行指针移动；在同一个屏幕中央按钮内完成按下和松开才退出。新增 macOS 27 触发角保护，清洁期间隐藏 Dock 和菜单栏，退出恢复。启动失败、失去前台、桌面变化、睡眠、权限撤销或输入保护失效时释放资源；补齐多屏按钮坐标与异步启动竞态处理。
- **系统 build 兼容范围**：深色模式、桌面隐藏与清洁模式按现有授权名单在 `26A428` 与 `26A434` 启用，其他 build 显示不可用原因。名单放行不代表完整实机矩阵已经通过。
- **图标与界面细节**：更新应用和菜单栏图标；处理状态保留固定空间，减少文字和开关位移。保留音量控制、全局快捷键、登录启动与本地设置。

## 下载与升级

- 下载 **MacSwitch-1.1.1-universal.zip**，解压后将 MacSwitch.app 移入“应用程序”；也提供 DMG 安装包。
- 两种安装包均包含 Apple Silicon（arm64）与 Intel（x86_64）架构。最低系统版本为 macOS 26.0；清洁模式还需要 macOS 27 的触发角保护接口及受支持 build。
- 升级前退出旧版本再替换应用，现有设置保留。更换版本后，辅助功能等权限与登录启动可能需要重新确认。
- 桌面持续隐藏首次开启需要允许访问“桌面”文件夹；隐藏期间，文件在 Finder“桌面”及打开/存储对话框中也会隐藏，⌘⇧. 可临时显示。文件仍保留原位。
- 当前使用 **ad-hoc 签名，尚未使用 Apple Developer ID 签名和公证**。首次打开可能提示无法验证开发者；确认来自本仓库后，可在“系统设置 → 隐私与安全性 → 仍要打开”为此应用建立例外。无需关闭 Gatekeeper。详见随附 FIRST-RUN.txt。
- 附带 SHA256SUMS.txt 与 MIT 许可证，可核对下载完整性。
